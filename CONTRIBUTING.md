# Contributing

Pull requests are welcome. Please keep the skill concise and focused on academic manuscript polishing.

Before opening a pull request, check:

- `SKILL.md` still has valid YAML frontmatter with `name` and `description`.
- New rules are general enough for computer-science and technical manuscripts, not limited to one paper or one algorithm.
- Wording guidance prefers field-common expressions over ornate or uncommon academic prose.
- New negative constraints must include one bad/good example pair.
- Output rules do not add labels inside manuscript text that users may copy into a paper.
- Examples are short and necessary.

For substantial changes, describe the manuscript-writing problem being solved and include one before/after example.
